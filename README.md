# Quamar Abrar — Portfolio

A single-page portfolio for Quamar Abrar, built with React, Vite, and GSAP.

## Development

```sh
pnpm install
pnpm dev
```

Create a production build with `pnpm build` and preview it locally with
`pnpm preview`.

Portfolio project content and the LinkedIn, Dribbble, and Instagram
destinations are maintained in `src/data.ts`. The design and motion handoff is
in `docs/portfolio-handoff.md`.
